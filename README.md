# 📉 LLM 评测与加密货币风控 Agent

> **先说清楚它不做什么**：它不预测涨跌，不承诺收益，也不是交易机器人。
> 它的核心是一套 **可证伪的 LLM 评测方法**，用来回答一个具体问题：
> **大模型到底能不能用来判断行情？如果不能，那它还能干什么？**

这是我用 42 个模型、600+ 次调用和 3000 根历史 K 线做出来的一手结论。

---

## 结论先行

| 问题 | 实测答案 |
|---|---|
| 多智能体协商能判断方向吗？ | **不能**。4 个模型准确率 54–61%，与"无脑猜多"无统计差异 |
| 换更强的模型能变准吗？ | **不能**。参数量与表现**无单调关系**（9B 小模型满分，超大 MoE 仅 60%） |
| 那 AI 在这件事上的价值是什么？ | **不是预测，是风控**——算清代价、强制纪律、暴露自己的错误 |

---

## 最有价值的部分：评测结果

### 1. 用「有标准答案的题」代替「主观打分」

第一轮我用主观题问模型"该做多还是做空"，结果只能看出谁话说得漂亮。
第二轮改成**客观题 + 多次采样**，结论完全不同：

| 题目 | 考察点 | 标准答案 |
|---|---|---|
| 事实提取 | 现价在均线上方还是下方 | 上方 |
| 仓位计算 | 按固定风险倒推仓位 | 0.0625 |
| 数据不足 | 只有费率时能否说"不知道" | 无法判断 |
| **止损爆仓陷阱** | **100 倍杠杆下止损与爆仓谁先触发** | **爆仓** |

**最后一道是分水岭。** 正确答案是爆仓（爆仓价 99.4975 比止损 95 更近），
但 **DeepSeek-V3 在 8 次里只答对 1 次**——而"防止这种坑"正是本项目的核心功能。

### 2. 参数量与表现无关

| 模型 | 参数量 | 正确率 | 陷阱题 |
|---|---|---:|---:|
| `Qwen/Qwen3.5-122B-A10B` | 122B | 100% | 5/5 |
| `zai-org/GLM-5.3` | 大型 | 100% | 5/5 |
| `deepseek-ai/DeepSeek-V4-Pro` | 超大 MoE | 100% | 5/5 |
| **`Qwen/Qwen3.5-9B`** | **9B** | **100%** | **5/5** |
| `Qwen/Qwen3.5-4B` | 4B | 87% | 3/5 |
| `deepseek-ai/DeepSeek-V3` | 超大 MoE | **60%** | **1/5** |

**9B 的小模型满分，几百 B 的大模型不及格。**
这道题考的不是智力，是**有没有老实按公式代入**——大模型凭直觉跳过计算。

### 3. 用样本外验证证伪自己

我用 3000 根 4 小时 K 线做条件统计，发现「贴近 30 根新高」策略：

```
持有 1 天   超额 +0.24%
持有 3 天   超额 +0.54%
持有 7 天   超额 +0.64%
持有 14 天  超额 +1.02%     ← 看起来是个可用规律
```

**切成 4 段做滚动验证后，只有 1–2/4 段仍然成立。**

判定为噪声，**主动放弃上线**。如果不做这一步，它就会以"有效策略"的身份进入产品。

### 4. 抓到的 LLM 可靠性缺陷

| 缺陷 | 影响 |
|---|---|
| 模型把资金费率 `0.002746` 读成 `0.2746%`（**放大 100 倍**），据此判定"费率极端高位"，方向结论整个反转 | 根因是喂入数字**未标注单位**。改为强制带单位后消除，并补回归测试 |
| 主持人漏判辩论中的数据错误——看空方正确指出看多方引用了错误数字，主持人却说"看多方数据更符合原始数据" | 加入**强制数据核对**步骤：逐个核对辩论中的数字，引错数据的一方要被降权 |
| `GLM-4.5-Air` 编造不存在的事实（说"价格跌破 MA20"，实际高于） | 淘汰 |
| `meituan-longcat/LongCat-2.0` 返回空内容 | 淘汰 |

## 功能

| 模块 | 作用 | 需要模型吗 |
|---|---|---|
| 📋 **交易方案生成** | 代码算结构位/止损候选/仓位/爆仓价，模型只负责**从候选里选** | ✅ |
| 🛑 开仓前检查 | 仓位倒推 + 爆仓价排雷 + 纪律闸门 | ❌ 纯代码 |
| 📒 交易日志 / 📊 绩效看板 | 胜率、盈利因子、R 倍数、最大回撤、情绪归因 | ❌ 纯代码 |
| 🔔 市场监控 | 9 类规则 + 冷却去重 + 持仓同步 | ❌ 纯规则 |
| 🌐 行情参考 / 多币种扫描 | 批量接口一次扫全部自选币种 | ❌ 只读行情 |
| 📰 市场情报 | 新闻事件识别（6 个 RSS 源）+ 链上数据（CoinMetrics / DefiLlama） | 部分 |
| 🤖 多智能体 | 4 家不同厂商模型 + 看多/看空两轮辩论 | ✅ |

### 关键设计：模型不允许凭空给价格

方案生成里，**代码算出一组候选止损位**（1/1.5/2/2.5 倍 ATR、近期摆动高低点、MA20/MA60），
**模型只能从中选一个并说明理由**。如果它编了一个候选表里没有的位置，程序会拒绝并回退到默认值：

```
⚠️ 模型选的「我自己算的 91.7」不在候选里，已回退到程序默认的「2倍ATR」。
   这一条不是模型的选择，请自行核对是否合适。
```

**每个数字都能追溯到公式或一个明确的理由。**

## 设计原则

1. **代码负责算，模型负责选** —— 确定性的事绝不交给 LLM
2. **模型产出必须可证伪** —— 每条判断都要回答"什么情况下我错了"
3. **多样化要来自制度，不是运气** —— 强制安排看多/看空研究员，避免四个模型同质化
4. **拒绝给方案是正常结果** —— 信号不清时不下手，比硬编一个方案专业
5. **数字必须带单位** —— 踩过坑：不带单位导致模型把 `0.002746` 读成 `0.2746%`

---

## 两条必须知道的限制

**① 止损不是万能保险。** 实测数据里有一笔单子记了止损，按计划该亏 45.5 USDT，
实际亏了 **132.10 USDT（3 倍）**——极端行情会击穿止损。**仓位小才是最后一道保险。**

**② 本项目不接交易所下单接口。** 交易所绑定只用于**只读**查询持仓（需自行申请只读权限），
代码中没有任何下单、平仓、划转、提现的调用。

## 风险提示

合约交易是高风险行为，杠杆会同时放大盈利和亏损，**绝大多数散户合约交易者是净亏损的**。

本项目是一个**评测工具与风控工具**，不构成任何投资建议，不保证收益，也不对交易结果负责。

**它不提高你的判断力，它阻止你把判断错误放大成灾难。**
