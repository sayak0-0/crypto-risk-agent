# 📉 加密货币合约交易助手

一个帮你**少亏钱、看清自己亏在哪**的合约交易 Agent。

它不预测价格，不帮你下单，也不承诺收益。它做三件很朴素但真正影响盈亏的事：

1. **开仓前先算清楚亏多少**（仓位倒推 + 爆仓价排雷 + 纪律闸门）
2. **每笔交易都留档**（自动算净盈亏、R 倍数）
3. **把亏钱的规律挖出来**（胜率/盈亏比/手续费/情绪/时段归因 + AI 复盘）

> **新版界面**：左侧是历史任务，右侧是一个问答窗口。可以直接输入「帮我看看 BTC」「扫描全市场异动」「看看新闻风险」，也可以点常用币种一键分析。原来的九页签完整保留，点左下角「交易日志 / 绩效 / 监控」即可进入。

## 一、先说清楚它「不能」做什么

| 想法 | 现实 |
|---|---|
| 让 AI 预测涨跌 | 做不到。没人能稳定做到。市面上号称能做的，基本在收学费。 |
| 让 AI 自动帮你赚钱 | 做不到。全自动量化对散户的期望收益是负的（手续费 + 滑点 + 被针对）。 |
| 跟单某个"大神" | 风险极高，且无法复盘自己的问题。 |

**所以这个项目走的是另一条路：不预测市场，只管住你自己。**

散户在合约里亏钱，绝大多数不是因为看不懂行情，而是这四个可控的东西：

- **仓位太大** —— 一单亏掉账户 20%
- **不设止损 / 挪止损** —— 小亏拖成大亏
- **单笔风险没有上限** —— 连亏 5 笔就出局
- **情绪化交易** —— 亏完立刻加倍开回来

这四件事，恰恰是工具能帮你拦住的。

## 二、它能做什么

### 🛑 开仓前检查（最有价值的一个页签）

你填：本金、单笔风险%、开仓价、止损价、目标价、杠杆。

它算：**这笔到底该开多少**，以及**这单该不该开**。

- **仓位是按风险倒推的，不是凭感觉**：先定死"这笔最多亏 1%"，再倒推能开多少币。止损放得远，仓位就自动变小；止损放得近，仓位才允许变大。
- **爆仓价排雷**：如果估算爆仓价比你的止损价还近，直接拒绝 —— 因为你会先被强平，止损单根本来不及成交。这是新手最常踩、也最致命的坑。
- **纪律闸门**：没止损 → 拒绝；单笔风险超 2% → 拒绝；盈亏比 < 1 → 拒绝；连亏到停手线 → 拒绝；当日超次数 → 拒绝。

### 📒 交易日志

每笔记录自动算净盈亏、R 倍数、持仓时长。CSV 中文表头，可以直接用 Excel 打开。

### 📊 绩效看板

胜率、盈亏比、**盈利因子**、期望值、**平均 R**、最大回撤、手续费占比，以及按币种 / 情绪 / 方向 / 时段的**归因分析**。

其中「平均 R」和「按情绪归因」是两个最容易被忽略、但最能说明问题的指标。

### 🔍 复盘

- **规则复盘（不花钱，先看这个）**：直接找出"手续费吃掉多少毛利""哪类情绪最亏""是不是报复性交易""最大单笔亏损是平均的几倍"。
- **AI 复盘（可选，走硅基流动）**：把指标和历史记录交给大模型，让它指出你行为模式上的问题。

### 🌐 行情参考

拉公开数据（资金费率、持仓量、多空比、4h ATR），翻译成**客观事实描述**，比如"资金费率偏高说明多头拥挤，追多成本高"。**没有买卖信号，不预测价格。**

### 🔔 市场监控（自用盯盘）

按你自己定的规则自动盯，触发就提醒。**比人盯盘靠谱，而且不会情绪化。**

九种规则类型：

| 类型 | 盯的是什么 | 为什么值得盯 |
|---|---|---|
| 价格上破 / 价格下破 | 价格穿过你定的线 | 最直接 |
| 24h涨跌幅超过 | 日内波动放大 | 异动往往有原因 |
| **资金费率超过** | 多空拥挤程度 | 币圈独有的情绪温度计，也是你的持仓成本 |
| 多空比高于 / 低于 | 散户是否一边倒 | 散户一致性高时，常是被反向收割的一方 |
| ATR超过 | 波动率突然放大 | 这时候你原来的止损距离很可能不够用了 |
| **距爆仓不足** | 你的仓位离强平还有多远 | **最保命的一条** |
| 距止损不足 | 你的仓位离止损还有多远 | 提醒你该执行计划了 |

两个实用设计：

- **冷却去重**：同一条警报不会刷屏。触发后会上锁，等条件恢复正常才重新上膛；
  但如果异常一直持续，超过冷却时间会再提醒一次（持续异常需要持续关注）。
- **持仓健康度**：记录你的持仓后，面板会实时显示浮动盈亏、距爆仓百分比、距止损百分比。

### 🔄 自动同步交易所持仓（不用手填了）

**在手机上开仓、加仓、平仓之后，点一下「同步」，这里自动更新。**

支持的交易所：**币安（USDT本位合约）、欧易 OKX、Bybit**。

同步后会告诉你发生了什么变化：

| 事件 | 举例 |
|---|---|
| 🟢 开仓 | `ETHUSDT 新开 空 仓 1` |
| ➕ 加仓 | `BTCUSDT 加仓：0.01 → 0.03` |
| ➖ 减仓 | `BTCUSDT 减仓：0.03 → 0.01` |
| 🔴 平仓 | `SOLUSDT 持仓已平掉` |
| 🔄 反手 | `BTCUSDT 方向从 多 变成 空` |

同步来的持仓会**自动保留你手动填的止损价**（交易所接口不返回这个），
所以「距止损不足」这类规则照样能用。

**安全边界（很重要）：**

- 本工具**只调用查询接口**，代码里没有任何下单、平仓、划转、提现的调用。
- 就算 Key 泄露，别人也只能看到你的持仓，**动不了你一分钱**。
- Key 存在 `.env` 里，已被 `.gitignore` 永久排除，不会进 git。
- 任何报错信息都不会包含你的 Key 或 Secret（有专门的单元测试在守着这条）。

### 🤖 多智能体判断（多角度看问题，不是预言机）

一个主持人 + 四位分工分析师：

| 角色 | 只看这些数据 |
|---|---|
| 技术面分析师 | 均线、近期高低点、ATR |
| 资金面分析师 | 资金费率、持仓量 |
| 情绪面分析师 | 多空账户比、24h 涨跌、区间位置 |
| 风控官 | 波动率、拥挤度（**不判断方向，只泼冷水**） |
| 主持人 | 汇总四人观点，**必须列出分歧**，输出可证伪条件 |

**四个设计，让它不至于变成骗人的东西：**

1. **每位分析师只看不同的数据切片** —— 故意不让他们看同样的东西。
   否则五个 agent 只是在互相复制观点，多 agent 数量再翻倍也没用。
2. **强制回答「什么情况下我错了」** —— 说不出可证伪条件的判断，都是废话。
3. **主持人被明确要求：多数一致不等于正确**，不许因为三人看多就下偏多的结论。
4. **每次判断都记录当时价格，到期自动结算对错**（最重要的一条）。

### 📋 生成交易方案（方向 + 入场 + 止损 + 止盈 + 仓位）

上面那些是「观点」。如果你要的是一份**能直接照着执行的完整方案**，用这个。

**核心设计：模型不做算术，代码不做判断。**

| 谁 | 负责什么 |
|---|---|
| **代码** | 算结构位、算 8 个候选止损位、按盈亏比反推止盈、算仓位、算爆仓价、跑纪律检查 |
| **模型** | 只负责**从代码算好的候选里选一个**，并说明为什么 |

**模型不允许凭空给价格。** 如果它编了一个候选表里没有的位置，程序会直接拒绝并报错：

```
❌ 方案官选了候选里没有的止损位「我自己算的 91.7」，已拒绝（防止编造价格）
```

这样每个数字都能追溯到**公式**或**一个明确的理由**。

**输出长这样：**

```
【BTCUSDT　做多】

  入场价      86,090.8512
  止损价      82,650.2786   （MA20下方，距入场 4.00%）
  止盈价      92,971.9965   （盈亏比 2:1）

  建议数量    0.002837
  名义价值    244.23 USDT
  占用保证金  24.42 USDT（本金 2.4%）
  止损时亏损  10.00 USDT（本金 1.00%）
  达到止盈赚  19.52 USDT

  估算爆仓价  77,871.1217　✅ 在止损之外
  保本价      86,176.9851

  纪律检查：通过
```

**候选止损位（全部由代码算出）：**

| 名称 | 依据 |
|---|---|
| 1 / 1.5 / 2 / 2.5 倍 ATR | 纯波动率止损，倍数越大越不易被扫 |
| 近期摆动低点外 | 近 20 根 K 线最低点再留 0.2×ATR 缓冲 |
| 前低外 / 前高外 | 更早一轮的极值，更强的支撑/阻力 |
| MA20 下方 / MA60 下方 | 跌破意味着短线/中期结构走坏 |

**⚠️ 三条必须知道的事：**

1. **方向判断本身没有变准。** 回测显示四个模型 54-61%，和抛硬币无统计差异。
   这个模块的价值在「把数字算到精确、把风险算到明处」，**不是提高胜率**。
2. **拒绝给方案是正常结果。** 如果方向判断是「中性」或「无法判断」，
   它会直接说「不构成开仓依据」。**信号不清时不下手，比硬编一个方案专业得多。**
3. **止损不是万能保险。** 实测数据里有笔单子记了止损，按计划该亏 45.5 USDT，
   实际亏了 132.10 USDT（**3 倍**）—— 极端行情会击穿止损。
   所以仓位小才是最后一道保险。

#### ⚠️ 请务必看这个数字

跑过几次之后，页面底部会显示：

```
总判断数 / 准确率 / 高信心准确率
```

**这是唯一能让你知道它到底准不准的东西。** 市面上的 AI 炒币工具只给结论、从不回头看自己准不准。
如果它跑了几十次准确率只有 48%，页面会直接告诉你「比抛硬币还差，不要按它的方向做单」。

我们的预期就是：**它大概率和抛硬币差不多。** 那它还有什么用？
—— 它逼你从四个角度看一遍，并且明确告诉你「什么条件下这个判断会被推翻」。
**那个条件本身才是真正有用的部分**，比方向结论有用得多。

有两种用法：

1. **网页版**：开着页面就行，可设 30 / 60 / 120 / 300 秒自动刷新。
2. **命令行常驻版**：双击 `启动市场监控.bat`，关掉浏览器也能一直盯，触发时还有提示音。

### 配置交易所 API Key（想自动同步持仓才需要）

**第 1 步：去交易所申请 Key**

### ⚠️ 先说币安的一个坑（重要）

**币安读 U 本位合约持仓，Key 必须开「允许合约（Enable Futures）」，而这个权限同时也允许下单交易。币安没有提供「只读合约」这个选项。**

这点必须讲清楚，不能含糊。所以配置是这样的：

| 权限项 | 怎么设 | 为什么 |
|---|---|---|
| 允许读取 | ✅ **必须开** | 不开什么都读不到 |
| **允许合约** | ✅ **要开** | 不开读不到合约持仓。但注意：这同时允许下单 |
| **允许提现** | ❌ **绝对不能开** | 本工具完全不需要。开了等于把钱包钥匙交出去 |
| 允许现货/杠杆交易 | ❌ 关掉 | 不需要 |
| 万能划转 | ❌ 关掉 | 不需要 |
| **IP 白名单** | ✅ **强烈建议绑** | 这是补上「合约权限」这个洞的唯一有效手段 |

**为什么 IP 白名单这么关键**：因为币安不给只读合约的选项，
所以「限制来源 IP」就成了唯一的保护。绑了之后，就算 Key 泄露，
别人从别的 IP 也调不动，等于废了。

> 如果你家宽带是动态 IP，白名单偶尔需要更新，这点要自己权衡。

### 三个交易所的入口和权限

| 交易所 | 申请入口 | 权限怎么勾 |
|---|---|---|
| **币安** | 网页版 → 头像 → **API 管理** → 创建 API | 读取 ✅ / 合约 ✅ / **提现 ❌** / 现货交易 ❌ / 绑 IP 白名单 |
| **欧易 OKX** | 头像 → **API** → 创建 V5 API | 权限选 **「只读」**（OKX 是三个里最干净的，只读就能读合约）；需要设 Passphrase |
| **Bybit** | 账户 → **API** → 创建新密钥 | Bybit 的 **「读取」** 权限即可读合约持仓，比币安安全 |

> 🌟 **如果你想最省心**：用 **OKX 或 Bybit**，它们的只读权限就能读合约持仓，
> 不用像币安那样被迫开交易权限。可以专门开个小账户放 OKX 做监控。

**第 2 步：创建完后先做权限体检**

### 🏠 本地模型会不会很笨？（重要）

**会笨一些，但要看干什么。** 先把账算清楚：

| 功能 | 需要模型吗 | 换小模型的影响 |
|---|---|---|
| 开仓前检查 | ❌ 纯代码计算 | **零影响** |
| 交易日志 / 绩效看板 | ❌ 纯代码 | **零影响** |
| 市场监控 | ❌ 纯规则引擎 | **零影响** |
| 规则复盘 | ❌ 纯规则 | **零影响** |
| AI 复盘 | ✅ | 影响较大，分析会变浅 |
| 多智能体判断 | ✅ | 影响中等 |

**前五项占了这工具 80% 的价值，一行模型都不用。** 所以「模型笨」影响的是锦上添花的部分。

#### 小模型的真实毛病（不是智力问题）

| 毛病 | 能不能治 | 怎么治 |
|---|---|---|
| 不守 JSON 格式 | ✅ 能治 | 给示例（few-shot）+ 输出校验 + 自动重试 |
| 说空话不引用数字 | ✅ 能治 | 提示词里强制「必须引用具体数字」 |
| 过度自信不肯说「无法判断」 | ⚠️ 部分能治 | 明确告诉它「无法判断是允许的」 |

我们**已经做了这些处理**：检测到小模型会自动切换成「精简提示词模式」
（带完整示例、必填字段从 6 个减到 4 个、句子改短），
解析失败会自动重试一次，并且**在结果里如实报告格式合规率**。

#### 与其猜，不如让它自证

在「🤖 多智能体」页签点 **🧪 先测一下这个模型行不行**，
它会花 1 次调用（约 200 tokens）让模型做一次结构化输出小测验：

- ✅ 通过 → 格式没问题，可以用
- ❌ 没通过 → 这个模型撑不住，页面会直接告诉你

正式分析时，结果上方也会显示 `四份结论格式合规：4/4`。
如果显示 `2/4`，说明模型确实跟不上，你立刻就能看出来，不会被它糊弄。

## 五、核心风控公式

**仓位（按固定风险倒推）**

```
允许亏损额 = 本金 × 单笔风险%
数量 = 允许亏损额 / (止损距离 + 手续费率 × (开仓价 + 止损价))
占用保证金 = 数量 × 开仓价 / 杠杆
```

注意：**数量只跟止损距离和风险额度有关，跟你用几倍杠杆无关。** 杠杆只影响占用保证金和爆仓距离。这就是为什么"高杠杆=高风险"这句话，在按风险算仓位时是不成立的 —— 真正决定风险的是仓位大小和止损距离。

**爆仓价（孤仓简化模型）**

```
做多：开仓价 × (1 - 1/杠杆) / (1 - 维持保证金率)
做空：开仓价 × (1 + 1/杠杆) / (1 + 维持保证金率)
```

⚠️ 这是**估算**。实际爆仓价还受全仓模式、未实现盈亏、资金费率累积、交易所分层维持保证金影响。**请以交易所 App 显示的为准**，本工具只用来提前排雷。

**盈亏比 vs 盈亏平衡胜率**

```
盈亏比 R 的情况下，不亏所需胜率 = 100 / (1 + R)
```

盈亏比 1.5 → 需要胜率 40%；盈亏比 1 → 需要 50%；盈亏比 0.5 → 需要 67%。

## 六、使用建议（怎么用才真的有用）

1. **只做记录，不改行为，两周后再看。** 你会看到自己的真实胜率远低于记忆中的数字。
2. **每笔交易先跑开仓前检查**，被拒绝就真的不开。这一步的收益大于任何指标。
3. **每周看一次「按情绪归因」**。多数人的亏损集中在两三个情绪标签上。
4. **手续费那一项要盯住。** 频繁交易者的手续费经常吃掉全部毛利。
5. 如果连续两周规则复盘都指出同样的问题，说明问题不在策略，在你。
